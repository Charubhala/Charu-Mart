# Charu Mart - Multi-Seller E-Commerce Marketplace

Charu Mart is a full-stack, multi-seller e-commerce web application built for individual capstone project evaluation. It enables seamless online shopping with distinct roles for Buyers, Sellers, and Admins.

## 🚀 Core Features
* **Role-Based Authentication:** Secure registration and login for Buyers and Sellers, with pre-seeded Admin access.
* **Seller Product Management:** Sellers can add, edit, delete, price, and manage stock for their products.
* **Product Browsing & Search:** Buyers can explore live listings, search, and filter by categories.
* **Shopping Cart & Checkout:** Add items, manage quantities, and complete simulated checkouts with instant order creation.
* **Order History:** Buyers can track past purchases and statuses (`PENDING`, `CONFIRMED`, `SHIPPED`, `DELIVERED`).
* **Admin Suite:** Centralized moderation to inspect users, manage orders, and moderate listings.
* **Product Reviews:** Post-purchase star ratings and written reviews.
* **AI Chatbot (Phase 3):** Server-side intelligent assistant answering customer FAQs and marketplace guidance.

## 🛠️ Technology Stack
* **Backend:** Node.js, Express.js
* **Database:** SQLite (File-based relational database)
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Version Control:** Git & GitHub
